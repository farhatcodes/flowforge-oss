# Pull request authorship

Open pull requests for this repository using the authenticated `farhatcodes` GitHub account. Every commit introduced by a pull request must be authored by that account. Omit co-author credits and `Co-authored-by` trailers from pull request descriptions and commit messages. Preserve the actual authorship of existing history. If a contribution has another author, raise it with the maintainer before opening a pull request.

Use an isolated checkout for repository work. Keep the host machine's Git identity, signing configuration, and credential store separate.
